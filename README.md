# GFX.Stats

`GFX.Stats` adds live FPS and rendering-performance panels to GFX applications
without introducing a general-purpose UI system.

```text
silex install GFX.Stats
```

## Documentation

- [Documentation française](Docs/FR/README.md)
- [English documentation](Docs/EN/README.md)

The package requires Silex 0.43.0 or newer.
